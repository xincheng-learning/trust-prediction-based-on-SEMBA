## 2. 本次实验一句话结论

在 `BitcoinOTC-1` 的严格在线 `sign_class` 任务下，把源用户历史行为、目标用户历史信誉、源-目标地位差等在线 status/asymmetry 特征加入 SEMBA decoder 后，`SEMBA-status-decoder` 在 5 个 seeds 上稳定优于原始 SEMBA，并且在主要指标上也超过 XGB 参照。

主结果如下：

| model | F1_negative | PR_AUC_negative | F1_macro | AUROC |
| --- | ---: | ---: | ---: | ---: |
| SEMBA | 0.3374 | 0.3882 | 0.6232 | 0.7360 |
| SEMBA-status-decoder | 0.5406 | 0.6001 | 0.7204 | 0.8537 |
| XGB-all-reference | 0.4900 | 0.5472 | 0.6970 | 0.8235 |

## 4. py：实验代码

| 文件 | 作用 |
| --- | --- |
| `py/build_online_status_features.py` | 构造严格在线 status/asymmetry 特征 |
| `py/run_semba_status_decoder.py` | 运行 SEMBA、SEMBA-status-decoder，并接入 XGB reference |
| `py/audit_strict_online_status_features.py` | 审计特征是否存在时间泄露 |
| `py/aggregate_status_decoder_results.py` | 汇总结果、生成表格和报告 |
| `py/__init__.py` | Python 包标记文件 |

核心模型形式：

```text
[z_src, z_dst, abs(z_src - z_dst), z_src * z_dst, online_status_features] -> MLP -> sign prediction
```
